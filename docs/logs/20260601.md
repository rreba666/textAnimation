- 每个快捷键触发时目标元素播放柔和的 GSAP 脉冲动画（缩放 + 外发光）

### 动画清单

| 动画 | 触发方式 | GSAP 效果 |
|------|----------|-----------|
| 打卡缩放 | 点击习惯圆点 | `fromTo` scale 1→0.5，back.out(3)，yoyo repeat |
| 待办入场 | 新增待办 | `from` opacity 0 + x -20，power2.out 0.35s |
| 脉冲反馈 | 按快捷键 | `fromTo` scale 1→1.03 + boxShadow 扩散，yoyo repeat |
| 删除收缩 | 点击待办删除 | `to` opacity+height+padding→0，power2.in 0.3s |
| 撤销恢复 | 点击 Toast 撤销 | `addTodo` 恢复数据，入场动画自动触发 |

### 删除撤销流程

```
点击删除 → GSAP 收缩淡出(0.3s) → deleteTodo(id) → Toast 弹出
                                                    ↓ 3秒内
                                          点击「撤销」→ addTodo(text) → toggleTodo(if completed) → 入场动画
                                          超时 3 秒 → Toast 自动消失
```

- 防重复：`deletingIds` Set 防止动画期间重复点击
- 数据备份：删除前快照 `{ text, completed }`，撤销时完整恢复
- 过滤兼容：恢复后自动出现在当前筛选视图中

